# 草地上的狗和袋鼠

## 题目描述

周末，小文和小康来到河湾动物园。她们看见一片草地，上面只有狗和袋鼠。

小文数了数狗的腿和袋鼠的后腿，一共数到 $n$ 条。每只狗计 $4$ 条腿，每只袋鼠只计 $2$ 条后腿。

请问，草地上狗和袋鼠的数量有多少种可能的搭配？如果两种搭配中狗的数量或袋鼠的数量不同，就算两种不同的搭配。草地上可以没有狗，也可以没有袋鼠。

## 输入格式

第一行包含一个整数 $t$（$1\le t\le100$），表示测试用例的数量。

接下来 $t$ 行，每行包含一个整数 $n$（$1\le n\le100$），表示数到的腿数。

## 输出格式

对于每个测试用例，输出一行一个整数，表示可能的搭配数。

## 输入输出样例 #1

### 输入 #1

```
5
2
3
4
6
100
```

### 输出 #1

```
1
0
2
2
26
```

## 说明/提示

当 $n=4$ 时，有两种可能的搭配。

- $1$ 只狗，$0$ 只袋鼠。
- $0$ 只狗，$2$ 只袋鼠。

当 $n=3$ 时，两种动物贡献的腿数都是偶数，答案为 $0$。
